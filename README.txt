GREEN - DJ site (GitHub Pages)

1. Create a free account at github.com and tap New repository. Name it green (or anything), set it to Public, and create it.
2. Tap "uploading an existing file". Drag in index.html AND the audio folder (unzip this first). Tap Commit changes.
3. Go to Settings > Pages. Under Branch pick main and folder / (root), then Save.
4. After a minute your site is live at https://YOUR-USERNAME.github.io/REPO-NAME/

To add a track later: upload the .mp3 into the audio folder, then add a line to the track list near the top of index.html (ask Claude to do this for you).
